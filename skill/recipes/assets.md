# Third-party assets

Only bring in assets with a game-safe licence. Accounts (Mixamo, Fab, Sketchfab) are signed in by the owner; agents never handle logins or passwords.

1. **Source.** Prefer CC0 (Poly Haven, ambientCG, Freesound CC0, Kenney), then CC-BY with credit, then store licences such as Mixamo. Read the licence on the source page itself and keep the URL. Non-commercial, no-AI and no-redistribution-in-games licences are out.
2. **Fetch CC0 in one command (Poly Haven, ambientCG).** `node tools/fetch-asset.mjs search polyhaven "barrel" --type model`, then `get polyhaven Barrel_02 --res 1k --dest <folder outside the repo>` (ambientCG: `get ambientcg Bricks105 --res 1k --unzip`; Poly Haven textures take `--maps Diffuse,nor_gl,arm`). It sends the identifying User-Agent Poly Haven requires, verifies Poly Haven's md5, saves to `<dest>/<source>/<id>/`, hard-codes CC0-1.0 (neither API returns a licence; both sites are CC0-only, so re-check their licence pages quarterly) and registers every file (step 3 done). Freesound, Kenney and Sketchfab stay manual.
   **Download by hand** into a folder outside any repo, such as `~/asset-sources/<kind>/<source>/<pack>/`. A browser download that stalls as a GUID `.tmp` is often finished but held by a hidden Save-as dialog: check it with `unzip -l` and copy it out.
3. **Register** (fetch-asset, make-sfx and gen-image do this themselves; by hand:) `node tools/asset-intake.mjs add --file <path> --source <url> --license <id> --author <name> --kind <kind> [--title] [--note]`. It refuses licences not on its allow list, and sets `ships: baked` for Mixamo, whose raw files never ship (baked motion, or a baked character mesh inside a game GLB, may ship if the current terms allow it). To allow a new licence, read its terms and add it to `LICENSES` in the tool, with the reason in the commit message. The register file is `ASSET-REGISTER.json` (git-ignored; `ASSET_REGISTER` overrides the path); `ASSET-REGISTER.example.json` shows the shape.
4. **Budget.** Before a file enters a game, check the game's asset budget (a manifest with a total-bytes cap, asserted by a script, works well). Shrink first: texture size (KTX2/WebP), mesh quantization, instancing, mono 48-96 kbps Opus/OGG for sound.
   Models made in-house with Blender (licence `OWN`; Blender is a GPL tool and its outputs are yours) follow [blender.md](blender.md). Optimize them with `--keep-nodes 1`.
   Models: `node tools/optimize-gltf.mjs in.glb out.glb --profile static --texture-size 512` for props (meshopt EXT + WebP, dedup, prune, simplify, join), `--profile skinned` for characters (no simplify/join/flatten/resample, so skins and clips survive; look at the render sheet afterwards). `--simplify-ratio R` (also sets `--simplify-error 0.01`, without which gltf-transform ignores the ratio) cuts triangles. `--engine gltfpack` (static only) simplifies well but can write larger files. Meshes come out quantized (KHR_mesh_quantization), so to instance one, multiply each instance by the mesh node's matrixWorld; do not bake the geometry. It prints bytes before and after plus the Khronos validator summary, and fails if the output holds `KHR_meshopt_compression` or Draco: drei/three-stdlib 2.36.1 reads only `EXT_meshopt_compression`, and drei's default Draco decoder path is a CDN a locked-down APK blocks. Setup: `npm ci` in the repo root; gltfpack goes in the git-ignored `bin/gltfpack-1.3/`.
   Sound: ffmpeg in `bin/ffmpeg.exe` (or set `FFMPEG`), a portable build, never a system install. Procedural sound: `node tools/make-sfx.mjs render --preset hit|block|click|pickup|footstep-dirt|footstep-stone|footstep-wood --seed 3 --out <file.ogg>` (jsfxr 1.4.1: retro and synthetic, fine for UI and placeholders) or `noise --kind wind|fire --seconds 8 --out <file.ogg>` (ffmpeg lavfi beds). Output is loudnorm'd mono Opus and is registered as licence `OWN`; vary a footstep by seed. For realistic world sound prefer a CC0 recording.
   Trim, then loudness-normalise and encode Opus: `ffmpeg -i in.wav -af loudnorm=I=-18:TP=-1.5:LRA=11 -ac 1 -c:a libopus -b:a 64k out.ogg` (music beds: stereo, 96k).
5. **Credit.** Every register entry with `credit: true` appears in the game's credits screen, or its attribution file, in the same commit that ships it.
6. Done when the asset is in the register, its budget test passes, and its credit is in place.

## Recorded voice-over (your own takes; licence OWN)

`node tools/voice-process.mjs` (the header has the full usage). Record one take per character, lines in script order, 2 s of silence between lines; a fluffed line is followed by 2 s of silence and a re-read (last take wins).
1. **Split.** `node tools/voice-process.mjs split <take.m4a> --keys char.line.1,char.line.2,... --strings <your strings file> --out <work>/raw` writes `<key>.wav` and `split-report.json`. With more segments than keys it keeps the later take of each run, scored against the line's expected length (characters / fitted speaking rate). **Read the report**: every `flags` entry (retake dropped, length off by 2.5x, lines missing) needs a human look; exit code 3 means low confidence. Fewer segments than keys means a line ran into the next: lower `--min-silence` or `--db`.
2. **Process.** `node tools/voice-process.mjs voice <key>.wav --profile deep-gruff|bright-high|tired-hard|young-thin --out <key>.ogg`: HPF 80 Hz, denoise, rubberband pitch and formant per profile, EQ, two-pass loudnorm to -18 LUFS / -1.5 dBTP, mono Opus 36 kbps. Profiles are in `tools/voice-profiles.json`; `calibrate` prints each profile's measured F0 and spectral-centroid shift on a synthetic voice. Tune `semitones` / `formantSemitones` by ear on the first real take, then keep the numbers.
3. **Ship.** Each file enters through `asset-intake.mjs` (licence OWN) and goes into the game's voice folder; list its key in the game's voice index.
